## Phase 3: Implement Code Fixes in src\app.py

Apply these specific fixes to create a memory-safe implementation:

### 3.1 Flask Configuration (Defense Layer 1)
- Set `app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024` (16MB)
- This provides Flask-level request size protection

### 3.2 Pre-Processing File Size Validation (Defense Layer 2)
- Define `MAX_FILE_SIZE = 10 * 1024 * 1024` (10MB)
- Check `file.content_length` or `len(file.read())` before image processing
- Return HTTP 413 with JSON `{"error": "File too large", "max_size_mb": 10}` if exceeded

### 3.3 Image Dimension Validation (Defense Layer 3)
- Define `MAX_PIXELS = 25_000_000` (25 million pixels)
- After opening image, check `image.width * image.height`
- Return HTTP 413 with JSON `{"error": "Image dimensions too large"}` if exceeded

### 3.4 Exception Handling (Defense Layer 4)
Wrap image processing code in try-except blocks:
- Catch `MemoryError`: return HTTP 413 with JSON `{"error": "Memory limit exceeded"}`
- Catch `PIL.UnidentifiedImageError`: return HTTP 400 with JSON `{"error": "Invalid image file"}`
- Catch generic `Exception`: log error, return HTTP 400 with JSON `{"error": "Processing failed"}`

### 3.5 Error Handlers
Add Flask error handler:
```python
@app.errorhandler(413)
def request_entity_too_large(error):
    return jsonify({"error": "Request too large"}), 413
```
